# Textured model example data

These models exercise the texture and color paths supported by
`pyvcad.TexturedMesh`.

## 3MF Consortium samples

Source: [3MF Consortium sample models](https://github.com/3MFConsortium/3mf-samples)

Files included:

- `3mf_consortium/sphere_logo.3mf`
- `3mf_consortium/pyramid_vertexcolor.3mf`
- `3mf_consortium/rhombicuboctahedron_color.3mf`

These files demonstrate packaged 2D textures, interpolated vertex colors, and
per-face color properties. They are distributed under the BSD 2-Clause License;
see `LICENSE-3MF-CONSORTIUM.txt`.

## Bison buffalo

Files included:

- `bison_buffalo/Bison_buffalo.obj`
- `bison_buffalo/Bison_buffalo.mtl`
- `bison_buffalo/material_0.png`

This user-supplied model demonstrates a detailed OBJ with UV coordinates and an
external diffuse texture. No separate license or provenance file accompanied
the supplied folder, so confirm its permitted use before redistributing it.

## Stanford dragon SSS test

Files included:

- `stanford_dragon_sss_test/Stanford_Dragon_SSS_Test.obj`
- `stanford_dragon_sss_test/Stanford_Dragon_SSS_Test.mtl`

This user-supplied model demonstrates a detailed OBJ whose appearance comes
from its MTL diffuse color. No separate license or provenance file accompanied
the supplied folder, so confirm its permitted use before redistributing it.
